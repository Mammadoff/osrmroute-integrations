# Integration engineering requirements

Use typed, focused code and authoritative OSRMRoute contracts. Preserve unknown coverage, errors, plan limits and credit costs. Never hard-code keys or send them to configurable origins. Bound payloads, timeouts and retries. Keep source/build tests, actual platform execution and catalog publication separate. Do not claim a draft integration is available. Run the relevant CI checks before releases. Keep user coordinates and credentials out of logs and artifacts.
