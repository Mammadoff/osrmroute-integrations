# OSRMRoute for Zapier — private beta

Platform UI integration: https://developer.zapier.com/app/248109/version/1.0.0

This integration is private. Authentication, the Platform tester and a live Find Address step in the Zap editor passed on 2026-10-19. It has not been submitted for App Directory review.

Invite URL: https://zapier.com/developer/public-invite/248109/2d51502f43640f7bbc18143a4424d8a1/

## Configuration

- API key: required password field `api_key`, with no default.
- Connection test: `authentication.js`, an authenticated MCP ping.
- Request template: empty URL parameters; `Authorization: Bearer {{bundle.authData.api_key}}` header.
- Find Address search: `find-address.js`; `q` is validated before a request, maximum 500 characters, one result.
- OSRMRoute scopes, plans and credit limits apply; this is not a separate credit allocation.

The JavaScript files are Platform UI code bodies with top-level returns, not independently executable modules.

## Verification

Run `node --test tests/*.test.cjs`. Local tests cover fixed credential destinations, failed authentication, empty results, malformed responses and invalid input without network calls.

## Live acceptance and publication boundaries

The initial connection failed with `401 bearer_required` because of Zapier's autogenerated query credential. Removing it and using the bearer header resolved the issue. A new user-submitted connection succeeded. The Platform tester returned Berlin, Germany with latitude 52.5173885 and longitude 13.3951309. Required input, response sample and labeled output fields are saved.

The validation panel reported zero functional errors. App Directory prerequisites still include a logo, a domain-matching team user, a successful live Zap, and at least three users with live Zaps. Do not simulate users to satisfy this requirement. Real workflow execution and catalog approval are separate from the successful Platform test.

## Usage

1. Accept the invitation and add OSRMRoute to a Zap.
2. Connect a dedicated active OSRMRoute API key with geocoding permission and a credit cap.
3. Choose **Find Address**, then map **Address or Place** from the previous step.
4. Use **Latitude**, **Longitude**, **Name** and **Country** in subsequent steps.
5. Test before enabling the workflow. No match returns an empty search result, not fabricated coordinates. OSRMRoute credit usage and Zapier task limits are independent.

This initial integration exposes Find Address only; other OSRMRoute APIs are not yet Zapier actions.
